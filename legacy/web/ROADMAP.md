## 建议顺序

1. **继续收拢运行时。** `src/game/GameRuntime.ts` 已从约 1,250 行降至约 950 行；下一步抽取玩家战技／投射物和遭遇伤害与奖励结算，使主文件只保留生命周期和主循环调度。每次抽取后跑现有测试与构建。
2. **完成监狱战斗表现。** 盾击数值和动作时序已接入，仍需要专用美术；把处决从“力竭时下一次 J/K 自动双倍”升级为带距离、朝向、动画与无敌窗口的明确交互；加入护甲减伤、负重和五出身可成长属性。精英已有前摇、突进、远程弹体和阶段数值差异，典狱长召唤狱卒以及完整 BOSS 动画仍需制作。
3. **完成监狱内容与成长。** 扩展侧室纵深，补齐剩余可放在监狱的碎片与隐藏路径，制作升级菜单。祭坛本地存档已能恢复永久进度；后续增加存档迁移和多存档位。
4. **制作外城与皇宫。** 将现有占位通道替换为完整关卡，按 GDD 地点接入商店、掉落、盾牌、法杖、圣典及武器专属战技；放入 F04、F08、F09 和其余剧情证据，完成勤王线能力的正常取得。先解决 `DesignIssues.md` 中 F04 与临时感知的规则冲突。
5. **美术和音效整合。** 已将提供的 64×96 角色、64×64 材质和透明道具图整理到 `public/assets` 并接入监狱场景；后续补齐精英、武器、动作帧、战斗特效和音效。资源需求见 `ART_BRIEF.md`。
6. **完整 Demo 验收。** 连续游玩两条叙事路线、检查全部 Fragment ID、装备来源、BOSS 阶段、存档恢复、键鼠操作与不同分辨率的界面。

## 运行时拆分边界

| 模块 | 拟承担的职责 |
| --- | --- |
| `GameRuntime` | Babylon 初始化、主循环顺序、系统连接和销毁 |
| `game/encounters`、`game/enemyProfiles` | 已抽出敌人目录与招式配置；遭遇伤害和奖励结算仍在运行时 |
| `game/playerAbilities` | 待抽：装备战技、祷言、灵魂箭、FP 与冷却 |
| `game/prisonInteractions` | 已抽：E 键调查、拾取、门、捷径、祭坛及区域切换的分发 |
| `game/GameVisuals` | 已抽：角色与装备网格、特效、光照、镜头和拾取物可见性 |
| `game/GameSnapshot`、`game/buildSnapshot`、`game/saveGame` | 已抽：UI 类型、快照组装与存档格式校验；存档应用仍在运行时 |

拆分前先为敌人遭遇、掉落和关键交互补少量跨模块行为测试，防止只通过类型检查却改变了实际流程。
