# 史诗碎片 · 监狱地图 Greybox

当前工程使用 TypeScript、Babylon.js、React、Vite 与 Havok。玩法、剧情和碎片编号以《Epic_Fragment_GDD_v0.1.3_5165.docx》为准；监狱拓扑按本轮新版地图方案扩展。场景继续使用基础几何体，方便调整平台高度和路线。

![大厅上方的二段跳入口](./prison-new-map-check.png)

## 可游玩路线

牢房 → 监狱走廊取回职业装备 → 下水道 → 通风管 → 中层走廊 → 档案室 F01 → 腐化骑士长廊 → 监狱大厅 F03。大厅左侧正门需要在祭坛提交 F01／T0＋F03／T1 的局部推论；这只开放王城公文通道，不直接给能力。右侧责难官为主线可选精英，击败后获得 F05。

F01＋F03＋F05 在祭坛解锁仅在监狱生效的临时灵力感知，返回大厅公告板调查 F07。外城与皇宫前厅目前是**通向 F10 的小型 Greybox 占位区**：击败前厅禁卫队长，再调查尸体取得 F10。回祭坛提交 F01＋F03＋F05＋F07＋F10，解锁二段跳。大厅上方的高台连接监狱二楼；二楼通道可从上方放下通往中层走廊的铁梯，之后永久双向通行。

![二楼与中层走廊之间的梯口](./prison-upper-loop-check.png)

二楼尽头的典狱长掉落 F12、钥匙串及戒指。钥匙打开责难官身后的锁门，进入拘押档案夹层，并接回大厅后楼梯通向的军械库外廊。长廊高台戒指、下水道花木戒指、通风管假墙原素瓶碎片、牢房 D 短刀及腐化骑士原素瓶碎片均可在相应位置取得。界面会提示附近可调查的物体与 Gate 条件。

## 操作

```bash
npm ci
npm run dev
```

`vite` 显示 `ready` 后会持续运行服务器；如果浏览器没有自动弹出，请打开终端显示的地址，通常为 `http://localhost:5173/`。结束时在终端按 `Ctrl+C`。

- `A`／`D` 移动，`W`／`Space` 跳跃；解锁二段跳后，在空中再按一次。
- `Shift` 疾跑，`J` 攻击，`E` 调查、使用门或梯子。
- `T` 打开时间轴；在大厅祭坛选择证据后，点击“在祭坛提交当前解释”或关闭面板按 `E`。
- 出生时可选五种出身；角色只穿囚服，职业装备和原素瓶在监狱走廊的没收架上取回。

## 当前范围

本轮实现的是**监狱地图与核心调查回访链的 Greybox**。责难官、典狱长、腐化骑士与禁卫队长有可击败的占位战斗；完整招式、五职业数值及装备效果、外城与皇宫完整关卡、存档系统仍未接入。F04、F08、F09 仍按 GDD 留在未建成的皇宫区域，因此勤王线疾跑突进目前只保留了匹配规则，无法在这个切片内正常取得。所有 Fragment ID 保持原编号；锁门后的档案夹层没有新增 Fragment。

```bash
npm test
npm run build
```

地图与平台在 `src/world/prisonLayout.ts`，时间轴 Gate 规则在 `src/world/prisonProgression.ts`，场景几何在 `src/game/prisonScene.ts`，交互与敌人在 `src/game/GameRuntime.ts`。设计冲突和范围见 [DesignIssues.md](./DesignIssues.md)。
