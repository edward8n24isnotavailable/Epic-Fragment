# 史诗碎片 · 监狱地图 Greybox

当前工程使用 TypeScript、Babylon.js、React、Vite 与 Havok。玩法、剧情和碎片编号以《Epic_Fragment_GDD_v0.1.3_5165.docx》为准；监狱拓扑按本轮新版地图方案扩展。场景继续使用基础几何体，方便调整平台高度和路线。

![大厅上方的二段跳入口](./prison-new-map-check.png)

## 可游玩路线

牢房 → 监狱走廊取回职业装备 → 下水道 → 通风管 → 中层走廊 → 档案室 F01 → 腐化骑士长廊 → 监狱大厅 F03。大厅左侧正门需要在祭坛提交 F01／T0＋F03／T1 的局部推论；这只开放王城公文通道，不直接给能力。右侧责难官为主线可选精英，击败后获得 F05。

F01＋F03＋F05 在祭坛解锁仅在监狱生效的临时灵力感知，返回大厅公告板调查 F07。外城与皇宫前厅目前是**通向 F10 的小型 Greybox 占位区**：击败前厅禁卫队长，再调查尸体取得 F10。回祭坛提交 F01＋F03＋F05＋F07＋F10，解锁二段跳。大厅上方的高台连接监狱二楼；二楼通道可从上方放下通往中层走廊的铁梯，之后永久双向通行。

![二楼与中层走廊之间的梯口](./prison-upper-loop-check.png)

二楼尽头的典狱长掉落 F12、钥匙串及戒指。钥匙打开责难官身后的锁门，进入拘押档案夹层，并接回大厅后楼梯通向的军械库外廊。长廊高台戒指、下水道花木戒指、通风管假墙原素瓶碎片、牢房 D 短刀及腐化骑士原素瓶碎片均可在相应位置取得。界面会提示附近可调查的物体与 Gate 条件。

## 操作

### 玩家：单文件可执行程序

`release/EpicFragment.exe` 把网页产物整体内嵌在可执行文件里，玩家机器**不需要安装 Node.js**，双击即玩。程序会在 `127.0.0.1:5173`（被占用时自动顺延）起一个本地服务器并打开默认浏览器；关闭命令窗口即结束。可选参数：`--no-open` 不自动开浏览器，`--port=8080` 指定端口。

Windows SmartScreen 可能因为可执行文件未签名而拦截，选择“更多信息 → 仍要运行”即可。

在开发机上生成这个文件：

```bash
npm ci
npm run build:exe
```

打包流程见 [`tools/build-exe.mjs`](./tools/build-exe.mjs)：先跑 `tsc -b` 与 `vite build`，再用 Node SEA 把 `dist` 下全部资源作为 asset 注入 Node 运行时副本（postject），产物约 92 MB。内嵌服务器入口在 [`tools/sea-entry.cjs`](./tools/sea-entry.cjs)。`build/` 与 `release/` 不进版本库。

### 开发：本地热更新

Windows：安装 Node.js 后，双击项目根目录的 [`start-game.cmd`](./start-game.cmd)。首次运行会安装依赖；启动完成后自动打开默认浏览器。游戏期间保留命令窗口，关闭窗口即停止本地服务器。

也可以在终端手动启动：

```bash
npm ci
npm run dev
```

`vite` 显示 `ready` 后会持续运行服务器；如果浏览器没有自动弹出，请打开终端显示的地址，通常为 `http://localhost:5173/`。结束时在终端按 `Ctrl+C`。

- `A`／`D` 移动，`W`／`Space` 跳跃；解锁二段跳后，在空中再按一次。
- `Shift` 疾跑，`J` 轻攻击，`K` 重攻击；单手持盾按 `Q` 盾击（耗 16 精力，削韧 12）。疾跑中按 `L` 闪避步，取回盾牌后按 `L` 弹反、按住举盾格挡。成功格挡后 0.5 秒内按 `J` 可反击，闪避结束后 0.2 秒内按 `J` 可接闪避攻击。法师取回法杖后按 `L` 发射追踪灵魂箭；牧师取回圣典后按住 `L` 输入 `W→S→W` 小回复、`W→A→D` 光辉武器或 `A→D→S` 神识，松开 `L` 施放。`R` 使用原素瓶，`E` 调查、使用门或梯子。原素瓶回复 40% 最大生命；生命、FP 和瓶数在祭坛补满，收集碎片会增加瓶数。
- 取回装备后，在左侧状态栏选择主手和副手；刺客额外拥有武器表中的盗贼短刀，拾取牢房 D 的短刀后其他出身也可装备短刀。按 `F` 切换单双手：双手攻击提高 20%，副手盾牌或圣典暂时失效。`L` 会随当前装备切换为盾牌防御、圣典祷言、直剑圣盾格挡、刺剑连续突刺、法杖灵魂箭、钉锤祝福或短刀闪避步。
- 左侧“武器图鉴”列出 GDD 的 27 件武器和 10 件盾牌／圣典、来源、属性补正与当前属性下的预估伤害。力、敏、智、信使用 GDD 的 S／A／B／C／D／E 补正系数；双手握持在补正后再乘 1.2。未建成地区的武器按 GDD 地点锁定，不进入装备选项。
- 敌人生命下方显示韧性。轻攻击削韧 8、重攻击 20、空中重攻击 15、弹反 25；连续突刺的每段削韧 8。韧性耗尽后敌人力竭 3 秒，期间下一次 J/K 近战命中造成双倍伤害。敌人 5 秒不受削韧后以每秒 10 点恢复。盾击已可用，基础伤害 12 属于 Greybox 暂定值。
- `T` 打开时间轴；在大厅祭坛选择证据后，点击“在祭坛提交当前解释”或关闭面板按 `E`。
- 出生时可选五种出身；角色只穿囚服，职业装备和原素瓶在监狱走廊的没收架上取回。
- 在监狱祭坛按 `E` 或通过时间轴提交解释，会补满资源并保存到当前浏览器本地。重开页面会自动载入；底部“载入存档”可手动恢复，“新游戏（清除存档）”会删除该存档。保存范围包括装备、碎片、时间轴、魂、拾取物、捷径与已击败的精英／BOSS；普通敌人和临时战斗状态在载入时重置。

## 当前范围

本轮实现的是**监狱地图与核心调查回访链的 Greybox**。责难官、典狱长、腐化骑士与禁卫队长有可击败的占位战斗；五出身初始属性、武器伤害补正、敌人韧性、盾击和祭坛本地存档已接入。牢房疯兵、腐化骑士、责难官、典狱长和禁卫队长有独立的攻击距离、前摇与动作配置；烙铁投掷与暗影弹已有飞行弹体，典狱长召唤狱卒及完整 BOSS 动画仍需制作。玩家、灰烬士兵、部分监狱材质和道具已使用像素素材；其他角色、武器与特效仍是占位表现。后续武器和副手的数值、来源已收录，未建成地区仍需制作取得途径、专属战技与特效。外城与皇宫完整关卡仍未接入。F04、F08、F09 仍按 GDD 留在未建成的皇宫区域，因此勤王线疾跑突进目前只保留了匹配规则，无法在这个切片内正常取得。所有 Fragment ID 保持原编号；锁门后的档案夹层没有新增 Fragment。

```bash

```
